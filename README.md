# ChoreMachine3000

## Description
Simple task manager, not like the windows one, but like the one you use once, and then never forget, kind of like a chore list. You can add chores, complete chores, delete chores, and thats about it. You have to set a priority for the chore, which is pretty arbitrary and you'll probably ignore anyway.

## Run how?
1. Clone this repo -> git clone https://github.com/intotheendlessnight/pa1-task-list
2. Navigate to wherever it is now on your computer, then double click index.html (if you're on linux you should know how to open a file though so I won't tell you how)
3. Enter the chore you need to do, set some priority, then delete or mark completed when needed!!
